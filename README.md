# はらぺこ横丁キッチン

ルームコードで集まる2D見下ろし型のオンライン協力料理アクション。2〜4人（1人でも可）。

- 公開URL（GitHub Pages）: https://pikumin17.github.io/coop-cooking-game/

## あそびかた

### 部屋の作り方と開始手順

1. ホストがルームを作成する
2. 表示されたルームコードまたは招待URLを参加者に共有する
3. 全員が準備OKにする
4. ホストがゲームを開始する

### 操作方法

| キー | 操作 |
| --- | --- |
| `WASD` / 矢印キー | 移動 |
| `Space` | 取る・置く |
| `E`（長押し） | 切る |
| `Shift` | ダッシュ |
| `1` 〜 `4` | スタンプ |
| `Esc` | メニュー |

### ルール

- 注文チケットに表示された料理を作って提供するとコインを獲得できます
- 注文の期限が切れると -20 コインになります
- 加熱しすぎると料理がこげます
- 皿は4枚あり、料理を提供したあと手元に戻ってきます
- 制限時間 180 秒でスコア（星1〜3）を目指します

## ローカルで動かす

ビルド手順はありません。静的ファイルサーバーで配信してブラウザで開きます。
